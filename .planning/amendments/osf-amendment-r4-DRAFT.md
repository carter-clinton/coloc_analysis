**Amendment to pre-registration osf.io/pvb5j: identity-LD versus reference-LD colocalization at curated cardiometabolic pleiotropy loci — head-to-head analysis plan (R4)**

**Date:** ‹CARTER-LOCK: posting date›

**Investigator:** Carter K. Clinton, NCSU ASHES Lab, ORCID 0000-0003-2669-8200.

**Status of this plan:** the analysis plan, configuration and code below are fixed by the analysis locked in commit ‹CARTER-LOCK: lock commit sha› before production. Production runs are refused unless an offline gate, checked when a production run is constructed and again as the first step of every production job, finds that the lock commit is an ancestor of the running code and that no frozen file in (m) has changed. Known-answer controls, data acquisition and panel construction ran before the lock and are reported below.

**Purpose:** to fix, before any production fit exists, the arms, estimands, decision rules, outcome branches, simulation design, negative controls and known-answer results of a matched comparison of linkage-disequilibrium (LD) handling in cross-trait colocalization.

**New analytical commitments:**

(a) **Hypothesis.** We test whether LD handling changes cross-trait colocalization calls at curated cardiometabolic pleiotropy loci. "Identity LD inflates colocalization" is one of five pre-specified outcomes, not a premise.

(b) **Arms.** All arms use identical summary statistics, regions, colocalization priors (p1, p2, p12) and SuSiE policy; `coloc.abf` uses its default effect-size priors, and SuSiE its defaults with the prior variance estimated. A1: `coloc.abf` (single causal variant; uses no LD matrix). A2 (`A2_identity`): SuSiE-RSS with R = I followed by `coloc.susie`. A3 (`A3_1kg`, reference): SuSiE-RSS with 1000 Genomes Phase 3 EUR LD followed by `coloc.susie`. A1 is not "identity LD": it assumes one causal variant per trait and reads no LD at all, whereas A2 fine-maps multiple signals under an identity matrix. A1 vs A3 compares the common literature method with fine-mapped colocalization; A2 vs A3 isolates the LD matrix. Sensitivity arms: `A3_ukb` (UK Biobank LD, native variant sets), `A3_ukb_isect` and `A3_1kg_isect` (both panels restricted to their shared variants). Secondary ancestry arm: AFR on 1000 Genomes AFR (`AFR661_A3`, `AFR661_A2`, `AFR504_A3`).

(c) **Data.** Five EUR traits (asthma, BMI, hypertension, stroke, type 2 diabetes; 10 unordered pairs) and three AFR traits (asthma, stroke, type 2 diabetes; 3 pairs). Inputs (sha256 recorded before production and verified inside every production fit, colocalization and QTL job for the summary statistics, variant catalogs and harmonized QTL files it reads; a mismatch or an unlisted input fails the job): asthma EUR, GBMI 2021, lifted to GRCh37 (below), `49edfc54ce3416844c855763ce710d1fd0171da2e9da6722a9fa09d0eb0c7e2b`; asthma AFR, GBMI 2021, lifted likewise, `8828df143702bc6128cf7872ba789fe76626dbe63344660bd84eb78a91c0c0c0`; BMI EUR, Yengo 2018, `c914e16b6b4e3264993c39db141090856e7e7fcdd1cad69405b04a2384acd9a0`; hypertension EUR, Evangelou 2018 systolic blood pressure, `a740bb261b58cbb9f284139dd0012cb7fc01df24095e9a14833118fac6eba78f`; stroke EUR, METASTROKE (Traylor 2012), `4dafe6152375b57e9b82033e92a3327df8a39f08fcea5dd3c86fda67394c3cd9`; stroke AFR, GIGASTROKE AFR GCST90104553 (small vessel stroke), `bf08ef2831b03a160857ef420ea448eeb38fac94a68b74359840d28e5d070384`; type 2 diabetes EUR, DIAMANTE 2022, `7cf7723ae0a6e6d05780d76ad53f922ec3a130c47ea38db26b1001911d6e4e8f`; type 2 diabetes AFR, T2DGGI (Suzuki 2024, effective N), `23347618a0cb31bd995aa49155ec933b276544e12f71e76279a66493eeb0470c`. (d) **Matched variants and the zero-credible-set fallback.** A2's identity payload is built from A3's variant frame, so A2 and A3 fit identical variant sets. A1 (primary, `matched`) runs on the intersection of the two A3 fits' variants; A1 on all region summary-statistic variants matched on position and unordered alleles (`allvars`) is a secondary row (rows lacking alleles match on position only). When either trait has zero credible sets under an arm, that row's outcome is `coloc.abf` on the same arm's variant set, labelled `fallback_abf`; by construction it equals A1 on that set. Fallback and `coloc.susie` values are never pooled silently: every estimand is reported on the subset where the arm produced `coloc.susie` and on all rows with fallback labelled, and the per-arm no-credible-set rate is a reported result. "Credible set" means the purity-filtered sets that `coloc.susie` reads (min_abs_corr 0.5). Fits still non-converged after the retry ladder in (k) are retained and enter colocalization. Pairs with a fit that exits before fitting (no variants, or more than 16,000 variants after restriction to the panel), and pairs for which `coloc.susie` returns no summary or no finite PP.H4, are kept as rows with method `none` and a recorded reason, excluded from the both-have-CS subset, and counted in a reported drop table (per contrast, p12 key and side: expected rows, outputs by method, `none` rows by reason, paired rows, both-have-CS rows). A fit variant name that is not a summary-statistic identifier is looked up in the variant table of the LD panel the fit used (the colocalization job checks that it was given that panel) and matched by position with an allele check: exact, swapped, or, for non-palindromic SNVs only, the strand complement of either; a name with no match, or with more than one candidate, is unmapped, and any unmapped name stops the pair with an error, so no variant is dropped silently.

(e) **Estimands.** Unit: one (region, ancestry, trait-pair) row of the static pair manifest. Region statistic S: for `coloc_susie` rows the maximum PP.H4 over credible-set pairs; for `fallback_abf` and A1 rows PP.H4. E1 (primary): Δ = S(X) − S(A3_1kg) for X ∈ {A1_matched, A2_identity}; median and mean with region-cluster bootstrap 95% CI; paired sign test (descriptive). E2: 2×2 agreement at PP.H4 ≥ 0.8 (primary) and 0.5 (secondary) and over {0.5, 0.7, 0.8, 0.9}; Cohen's κ; exact two-sided McNemar test with b = X calls H4 and A3 does not, c = the reverse (descriptive; the direction category is decided by the region-level test in the block below). E3: cross-tabulation between arms of the argmax hypothesis (H0–H4) of the row's reported PP vector (for `coloc_susie` rows, the credible-set pair with the maximum PP.H4; ties take the first). E4: per fit, number and size of credible sets and L saturation; for every fit with credible sets, whatever its convergence status, cross-evaluated purity: A2 sets against the 1000G R; `A3_ukb` and `A3_1kg` native sets against each other's R; `A3_ukb_isect` and `A3_1kg_isect` against each other's R; and the AFR analogues (`AFR661_A2` against `AFR661_A3`; `AFR504_A3` and `AFR661_A3` against each other). Between panels with different variant sets (native UK Biobank and 1000G; AFR504 and AFR661) purity is computed over the set members present in the other panel and is undefined when fewer than two members (one, for a single-variant set) are present; elsewhere an absent member is an error.
