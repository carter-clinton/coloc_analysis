**New analytical commitments:**

(a) **Hypothesis.** We test whether LD handling changes cross-trait colocalization calls at curated cardiometabolic pleiotropy loci. "Identity LD inflates colocalization" is one of five pre-specified outcomes, not a premise.

(b) **Arms.** All arms use identical summary statistics, regions, colocalization priors (p1, p2, p12) and SuSiE policy; `coloc.abf` uses its default effect-size priors, and SuSiE its defaults with the prior variance estimated. A1: `coloc.abf` (single causal variant; uses no LD matrix). A2 (`A2_identity`): SuSiE-RSS with R = I followed by `coloc.susie`. A3 (`A3_1kg`, reference): SuSiE-RSS with 1000 Genomes Phase 3 EUR LD followed by `coloc.susie`. A1 is not "identity LD": it assumes one causal variant per trait and uses no LD values, whereas A2 fine-maps multiple signals under an identity matrix. A1 vs A3 compares the common literature method with fine-mapped colocalization; A2 vs A3 isolates the LD matrix. Sensitivity arms: `A3_ukb` (UK Biobank LD, native variant sets), `A3_ukb_isect` and `A3_1kg_isect` (both panels restricted to their shared variants). Secondary ancestry arm: AFR on 1000 Genomes AFR (`AFR661_A3`, `AFR661_A2`, `AFR504_A3`).

(e) **Estimands.** Unit: one (region, ancestry, trait-pair) row of the static pair manifest. E3: cross-tabulation between arms of the argmax hypothesis (H0–H4) of the row's reported PP vector (for `coloc_susie` rows, the credible-set pair with the maximum PP.H4; ties take the first). E4: per fit, number and size of credible sets and L saturation; for every fit with credible sets, whatever its convergence status, cross-evaluated purity: A2 sets against the 1000G R; `A3_ukb` and `A3_1kg` native sets against each other's R; `A3_ukb_isect` and `A3_1kg_isect` against each other's R; and the AFR analogues (`AFR661_A2` against `AFR661_A3`; `AFR504_A3` and `AFR661_A3` against each other). E8: simulation calibration (g). The confirmatory analysis is exactly:

- Contrasts: A1_matched_vs_A3_1kg, A2_identity_vs_A3_1kg; reference arm A3_1kg.
- Row set: pair-manifest rows with row_class = primary, ancestry = EUR, admissible = true, p12_key = p12_primary, a1_varset = matched.
- Bootstrap clusters: region_safe of the confirmatory rows.
- Both-have-CS subset per contrast (A2_identity_vs_A3_1kg: both methods coloc_susie; A1_matched_vs_A3_1kg: A3 method coloc_susie).
- Confidence interval: median_delta_pph4 on the both_have_cs subset by region_cluster_bootstrap_percentile, 10000 resamples, seed 20261021, level 0.95.

- Region-level sign-flip test (decides the mcnemar category): on the both_have_cs subset; a call is region_stat >= threshold_primary; d_r = b_r - c_r per region (b = X calls H4 and A3 does not; c = the reverse); T = sum of d_r over regions; p = two-sided P(|T*| >= |T|) over all 2^k sign assignments of the k regions with d_r != 0, exact when k <= 20; if k > exact_max_k: bootstrap_B draws with bootstrap_seed, p = (1 + #{|T*| >= |T|}) / (B + 1) (bootstrap_B = 10000, bootstrap_seed = 20261021).

- Classifier precedence (first match wins): n_both, ci_includes_0, ci_mcnemar_agree, partial_rule.
- Never classifier inputs: negative_control rows (pre-specified specificity analysis); AFR rows (secondary); p12_sensitivity; A1 allvars; A3_ukb / A3_ukb_isect / A3_1kg_isect (E6); repro arms.

(f) **Decision rule.** Cut-offs: kappa_cut = ‹CARTER-LOCK: kappa_cut, proposed 0.6›; n_both_min = ‹CARTER-LOCK: n_both_min, proposed 10›; p12 (primary) = ‹CARTER-LOCK: p12_primary, proposed 5×10⁻⁶›, p12 sensitivity 1×10⁻⁵, p1 = p2 = 1×10⁻⁴ for every arm. p12 = 5×10⁻⁶ follows Wallace (2020, PLoS Genet 16:e1008720), whose simulations suggest the coloc default of 10⁻⁵ "may be overly liberal" and that 5×10⁻⁶ "may be a more generally robust choice"; the paper's closing Discussion sentence printed 5×10⁻⁵ and was corrected to 5×10⁻⁶ (Wallace 2026, PLoS Genet 22:e1012155). (g) **Simulation (E8, secondary).** For each of the 10 admissible regions, a window of 1,000 contiguous panel variants centred on the panel midpoint (all variants if fewer) is taken from the intersection-matched panels. z-scores are drawn independently for the two traits as z ~ N(R s, R) from a PSD-clipped generation matrix R, with s = 7 at each causal variant and n = 100,000 per trait (config key `n_per_trait`; a bare `n:` key is read as FALSE by R's YAML parser, so it was renamed before any run). Scenarios: H0 (no causal variant), H4 (one shared causal variant) and H3 (distinct causal variants with r² in [0.25, 0.35], [0.55, 0.65] or [0.85, 0.95] under the fitting panel). Generation panels: 1000G EUR and UK Biobank (reference mismatch); the fitting panel is always 1000G EUR. 200 replicates per cell; one seed per replicate: seed = 20261021 + the position of (region, scenario, generation panel, replicate) in a fixed sorted order. A1, A2 and A3 run through the same fitting ladder and colocalization code as the real data at p12 primary; a fit that the ladder cannot produce is not refitted with R = I, and that arm's replicate is recorded with method `none` and the failing fit status. Reported: share of replicates with S ≥ 0.8 per arm, method, scenario and generation panel (false-H4 under H0/H3, true-H4 under H4), with Wilson 95% intervals; `coloc_susie` and `fallback_abf` replicates are never pooled, and `none` replicates are counted without a rate. Cells with no qualifying causal pair are counted, never filled in. Aggregation refuses to run unless all 100 cells are present, each with exactly the configured 200 replicates per arm or recorded as having no qualifying causal pair, and no cell is present that the design does not list.
