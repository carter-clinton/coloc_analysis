- hess_local_rhog (line 1045)      : input.bfile_bim, input.partition -> needs download_hess_panel

Chosen approach (approach c — minimum disruption, correct wiring):
  Add flag-file dependencies as EXTRA inputs to each consumer rule. The flag
  files already exist as download-rule outputs, so declaring them as consumer
  inputs creates the missing DAG edges without changing shell commands, without
  forcing per-chromosome output declarations, and without touching config/.
  Shell blocks continue to reference the specific side-effect filenames (bim,
  bed, ldcts, etc.) via params/inputs as today — Snakemake treats them as
  present once the flag file is present.
