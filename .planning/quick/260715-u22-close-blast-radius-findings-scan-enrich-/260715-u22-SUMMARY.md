## Task 1 — the scan→enrich seam (`63bdb59`)

`enrich_occlusion_manifest` looked the 07c hand-off up by the GRCh38-derived
`variant_id` string; the 07c producer RED pins `scan_present_rate` to a
`(chr, pos_grch37)` GRCh37 tuple key (`test_occlusion_present_rate_scan.py:72` —
`target = (1, 5_982_778)`). A dict `.get()` miss is silent, so building 07c exactly to
its RED would have blanked `traits_present` / `n_traits_present` / `n_traits_scanned`
to `pd.NA` across all 276 regions — indistinguishable from a real k=0 — silently
erasing the rs182965575 "present in 7 of 9 AFR sumstats" evidence that retired NaN→0
and is published as the osf.io/az52u provenance, **with both suites green**.

**Fix:** `_present_rate_key()` (explicit `(chr, pos_grch37)`, `None` when unlifted);
the join moved post-lift inside `enrich`; a total-miss guard **scoped to liftable rows
only**; docstring corrected to the real contract + the exact three-way raise boundary.

## Task 2 — panel-TSV header reconciliation (`fe375e7`)

`_append_panel_row_local` gated the header on file **existence** only and never
compared `list(existing.columns)` to `_PANEL_COLUMNS`. m3-07b's 8→9 widening armed it
(the second arming — `ed9cfd4` already did 7→8).

**Empirically reproduced pre-fix, not assumed:**

```
field counts per line: [8, 8, 9]
next-region dedup read raises: ParserError -> Expected 8 fields in line 3
```

`append_panel_row` is called at `:808`, **outside** the per-region try/except, and the
main loop wraps `process_region` in no try — so that `ParserError` is uncaught and the
billed ~11-day fire aborts after ~2 regions of compute.

**Fix:** a `ValueError` naming both column lists and telling the operator to rotate the
stale file, placed **before** the dedup read (ordering is load-bearing: a shifted stale
file can `KeyError` on `region_id` first and mask the diagnosis). The guard **refuses,
never repairs** (`feedback_skip_guard_masks_not_fixes`). The `gs://` path routes through
this same function on its local mirror, so one guard covers both.
