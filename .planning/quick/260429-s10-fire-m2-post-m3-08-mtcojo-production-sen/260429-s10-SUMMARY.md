## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical functionality] Auto-prune empty HM3 covariates**
- **Found during:** Task 3 pre-flight smoke
- **Issue:** Initial smoke (commit `4d75bea` build_cojo_inputs.py) materialized
  HM3-intersected cojo files for all 8 EUR covariates per the residcov sidecar.
  `sbp.EUR.Evangelou-ICBP-UKBB.2018` and `stroke.EUR.GIGASTROKE.2022` produced
  0-row cojo files because their harmonized sumstats use `chr:pos` (sbp) and
  `chr:pos:A1:A2` (stroke) identifiers, neither of which intersects the
  rsID-keyed HapMap3 SNP list. GCTA mtCOJO LDSC step terminated with the
  same witness phrase from the legacy run ("no SNP in common between the
  summary data and the LD score files") because the per-pair
  target ∩ covariate ∩ ld-score intersection is empty for an empty
  covariate.
- **Fix:** Extended `build_inputs()` with auto-prune logic: when
  `hm3_snplist` is supplied, covariates with 0 HM3-intersected SNPs are
  dropped from the emitted `.mtcojo.list` with an explanatory log line.
  Empty target raises ValueError. Legacy genome-wide path (`hm3_snplist=None`)
  is unchanged.
- **Files modified:** `src/python/build_cojo_inputs.py`, `tests/m2/test_build_cojo_inputs_hm3.py` (added Tests 6+7)
- **Commit:** `28f06d3`

**2. [Rule 1 - Bug] Wrong canonicalize-extension list in LSF driver**
- **Found during:** Task 3 smoke v2 successful GCTA run
- **Issue:** Initial driver (commit `3f17dbf`) checked for `.mtcojo.cma.cojo`
  / `.cma.cojo` / `.cma` / `_cojo` extensions to canonicalize the GCTA
  output. Witnessed during smoke that GCTA actually writes
  `<prefix>.mtcojo.cma` when `--out=<prefix>` is `<target>.mtcojo`,
  giving an actual filename of `<target>.mtcojo.mtcojo.cma`. Driver's
  `test -s "$OUT_PREFIX.cojo"` sentinel would have failed for every
  job even on a successful GCTA run.
- **Fix:** Added `.mtcojo.cma` and `.cma` to the head of the extension
  search list in the per-target jobscript template. Existing extensions
  retained as fallbacks.
- **Files modified:** `bin/fire_m2_post_m3_08_mtcojo.sh`
- **Commit:** `cbb4261`

Both deviations were caught BY the rigor-gate smoke (Task 3) — exactly
the purpose for which the rigor gate exists. Without the gate, the LSF
burst would have fired with broken canonicalization AND the Rule 2
empty-covariate bug, wasting ~30 min of LSF wall on 13 jobs that would
all fail at the same LDSC step.
