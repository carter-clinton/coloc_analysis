### T3 — an honest note on the span-filter reds

**The Layer-1 edits did not produce a meaningful red, and saying otherwise would be false.**
They *weaken* two equalities into containment inside a test that **SKIPS** outside the AoU
perimeter, so they were green-by-construction the moment they were written. A weakened
assertion that has never been seen to fail is decoration, so rather than manufacture a red the
batch added an **unconditional** control,
`test_containment_assertions_discriminate_a_wrong_answer`, which runs both containment shapes
against deliberately wrong inputs and asserts they detect the defect:

```python
got = {10328, 44784}                      # a detector that lost three of the settled five
missing = _REGION1_REAL_WINDOW_OCCLUDED_ROW_INDICES - got
assert missing == {46714, 59097, 66730}   # -> the gated assertion WOULD fail

have = Counter([60, 29, 7, 31, 17, 29, 170, 4, 4])   # one 31-bp span short
short = {span: (n, have[span]) for span, n in want.items() if have[span] < n}
assert short == {31: (2, 1)}              # -> the gated assertion WOULD fail
```

It also asserts silence on a **superset** (the real-window case), so it discriminates in both
directions. The **Layer-2** test's red is its absence: it did not exist, and it lands as a SKIP
here for want of `data/aou/region1_window.bim`. Both facts are stated rather than dressed up.
