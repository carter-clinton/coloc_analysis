**Step 1 — write `260820-s2x-instantiate.py`.** A single-purpose script. It must:

  a. Read `.planning/debug/260820-site-basis-sweep-results-as-received.md` and parse the SEVEN
     Class-M values out of the four verbatim summary lines by regex (`SITE-BASIS SUMMARY n=21:
     min=… median=… max=…; robust_sigma(1.4826*MAD)=…`, `CANDIDATE CEILING … : …`, `margin over
     observed site-basis max: …`, `mean row/site inflation across sample: …`). Parsing the
     banked file — not accepting them as arguments — is what makes the record the source.

  b. RECONCILE the parsed aggregates against the per-region table in the same file
     (21 data rows). Recompute from the `site_frac_pct` column: min, median, robust sigma
     (1.4826 x MAD), max; and the mean of the `inflation` column. Require each to agree with
     the parsed summary value to <= 0.0001 (percentages) / <= 0.005 (inflation). Then require
     |CEILING_3X_MEDIAN_PCT - 3*median| <= 0.001 and |CEILING_MARGIN_X - ceiling/max| <= 0.02
     (the guard's own tolerances — the printed ceiling was computed from the unrounded median,
     so this is an inside-tolerance check, NOT an equality check). Any failure = abort, write
     nothing. *An aggregate can agree while its components are wrong; check the components.*

  c. Compute the four DERIVED values by the draft's formulas (lines 74-79 of the draft).

  d. Render: percentages `f"{v:.4f}%"`, ratios `f"{v:.2f}x"`. Take `PRE_EXECUTE_COMMIT` and
     `POSTING_DATE` from argv.

  e. Assert every rendered value matches the guard's own filled-value regex for its slot
     BEFORE writing (so the script, not the guard, is the first thing to notice a bad render).

  f. Substitute `{{NAME}}` -> value for all 13 slots across the whole file. Before writing:
     count `{{` and `}}` in the input, sum the per-slot replacement counts, and assert
     `sum == n_open == n_close` and that every slot had >= 1 occurrence. After writing: assert
     zero `{{` and zero `}}` remain. Abort (writing nothing) if the input has zero `{{` — that
     means it is already instantiated and this is an accidental second run.

  g. Print a SUBSTITUTION LEDGER to stdout: one line per slot as
     `SLOT | VALUE | OCCURRENCES | SOURCE(parsed|derived|argv)`, plus the totals line. Capture
     this stdout — it goes verbatim into the SUMMARY.
