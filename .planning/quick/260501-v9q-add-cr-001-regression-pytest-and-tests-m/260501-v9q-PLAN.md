<objective>
Lock the CR-001 fix (commit 6d2e753) behind a regression test so the silent
fallback bug — both `{region_id}` and `{region_safe}` placeholders being filled
with the same value — cannot reappear undetected.

CR-001 root cause: pre-fix, `resolve_ld_path()` did
`entry["path"].format(region_id=region_id, region_safe=region_id)` (single
arg). Post-fix, `region_safe` is an independent kwarg. The existing
`test_resolver_region_id_vs_region_safe_substitution` only exercises the
single-arg back-compat path — it does NOT exercise the bug CR-001 fixed,
because it uses a config in which both buckets resolve to the same filename.

This plan adds three regression tests and a parity `__init__.py`:
1. AoU-head test with DISTINCT region_id (`m2_region_00067`) and region_safe
   (`FTO_16q12`); only the AoU bucket has the file → asserts resolver returns
   the AoU path. Pre-fix code would have looked for `FTO_16q12.rds` in the
   AoU bucket and missed it.
2. 1kg-fallback test with DISTINCT values; AoU bucket empty, 1kg bucket has
   only `{region_safe}.rds` → asserts resolver returns the 1kg path. Pre-fix
   code would have looked for `m2_region_00067.rds` in the 1kg bucket and
   missed it (cascading FileNotFoundError).
3. Static-grep test on `src/snakemake/rules/finemap.smk` asserting the
   production call site passes both `region_id=` and `region_safe=` kwargs.
   Locks the call-site contract so a future refactor that drops one kwarg
   (and silently regresses to back-compat single-value substitution) is
   caught.

Purpose: regression-prevention only. Hermetic, no Hail/AoU/network deps.
Output: 3 new tests + 1 empty `__init__.py`. Existing 8 tests remain unchanged.
</objective>

def resolve_ld_path(

    ancestry: str,
    config: dict,

      FileNotFoundError if strict_aou_only=True and AoU panel missing.
      FileNotFoundError("No LD panel found ...") if no chain entry resolves.
    """

    def test_resolver_distinct_region_id_and_region_safe_aou_head(tmp_path):
        """AoU head: DISTINCT region_id vs region_safe; only AoU file exists.

        Pre-CR-001: resolver would have looked for `FTO_16q12.rds` in the
        AoU bucket (since both placeholders got the same value) and missed
        it, walking to hgdp/1kg fallback. Post-CR-001: returns the AoU path.

        base = tmp_path / "data" / "processed" / "ld_reference"

        rid = "m2_region_00067"   # AoU naming
        safe = "FTO_16q12"        # Track A naming — DISTINCT from rid

        # Only the AoU bucket has the file (named by region_id).
        aou_path = _touch(base / "AFR_aou" / f"{rid}.rds")

        # No FTO_16q12.rds anywhere — guard against accidental cross-bucket hits.
        assert not (base / "AFR_aou" / f"{safe}.rds").exists()
        assert not (base / "AFR_hgdp_1kg" / f"{safe}.rds").exists()
        assert not (base / "AFR" / f"{safe}.rds").exists()

        got = resolve_ld_path(
            region_id=rid,
            ancestry="AFR",
            config=cfg,
            region_safe=safe,
        )
        assert got == aou_path
        assert got.name == f"{rid}.rds", (
