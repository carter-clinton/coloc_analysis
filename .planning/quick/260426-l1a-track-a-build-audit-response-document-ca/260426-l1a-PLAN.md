<status_taxonomy>
Each row in the matrix gets exactly ONE status:

- **CLOSED** — change is committed; evidence (commit hash + file modified) verifiable on disk.
- **IN-PROGRESS** — partial commit landed, more work scheduled inside Track A.
- **DEFERRED-COMPUTE** — closure requires LSF compute (e.g., HQ#2(i) SH2B3 L=20 re-fit). Recorded as Track A residual; will be picked up in a future quick task.
- **DEFERRED-DESIGN** — closure requires user judgment beyond what existing evidence supports (e.g., the "drop or flag non-converged in yield counts" decision in HQ#2(ii) if the user wants to keep them).
- **NO-ACTION-NEEDED** — audit observation accepted as-is (e.g., Eval 4(b) "bidirectional provenance" was acknowledged in the audit itself as workable; no remediation required).
- **SUPERSEDED** — item closed by closure of another item (e.g., QI#2 closed via Eval 3.7 closure). Cite the parent commit.
</status_taxonomy>
