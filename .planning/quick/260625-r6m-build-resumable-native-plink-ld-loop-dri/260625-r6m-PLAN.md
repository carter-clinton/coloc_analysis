STEP 5 content-verify contract (from the fire brief; this is the verify spec):
```python
ld = npz["ld"]; n = ld.shape[0]
assert ld.dtype == np.float32 and ld.shape == (n, n)   # float32, square
assert abs(float(ld[0, 0]) - 1.0) < 1e-3               # diag == 1.0
assert np.allclose(ld, ld.T, atol=1e-4)                # symmetric (square mode)
# banded mode: verify lower_triangular==True + np.triu(ld, k=1) all-zero instead
```

n_var derivation (square): the per-region variant count == number of .bim rows whose
bp falls in [from_bp, to_bp]. The square .ld.bin holds n_var**2 little-endian float32,
so n_var = int(round(sqrt(filesize_bytes / 4))). Derive n_var from the .ld.bin size and
CROSS-CHECK against the count of .bim rows in the window (load_bim gives full-cohort
order; the driver must subset to the window — see action). plink_ld_to_npz then receives
that n_var and the WINDOW-SUBSET .bim. (For banded, n_var = window .bim row count.)
