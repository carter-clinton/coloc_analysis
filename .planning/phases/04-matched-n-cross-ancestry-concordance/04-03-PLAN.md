Create `src/snakemake/scripts/compute_tier_a_retention.R`. Header must include:
```r
# D-02a PRIMARY METRIC: Tier A retention fraction per trait
# D-02e EXPLICITLY NOT REUSED: Phase 9 joint PP.H4 + effect-size criterion
# (reason: conflates coloc stability with effect-size stability, would
# double-count power loss and inflate observed concordance reduction).
```
Logic:
1. Load Phase 2 `tier_assignments.tsv`; filter to `ancestry=='AFR' AND tier=='A'` -> `afr_tier_a_loci` per trait.
2. For each trait x bootstrap b in 1..100: load all `coloc_summary.tsv` under `results/matched_n/coloc/{trait}/*/bootstrap_{b}/`. For each locus, compute `is_tier_a_b = (pph4 >= 0.8) AND (at_least_one_qtl_coloc_pph4 >= 0.8)`.
3. `retention_b = |{loci where is_tier_a_b}| / |afr_tier_a_loci|` per bootstrap.
4. Aggregate across 100 bootstraps: `mean_retention = mean(retention_b); ci95 = quantile(retention_b, c(0.025, 0.975))`.
5. Write `results/matched_n/tier_a_retention.tsv` with columns `trait, n_afr_tier_a, mean_retention, ci95_lo, ci95_hi, n_bootstraps`.
6. Also compute the **unmatched** concordance baseline for H7 (per D-02d): one pass over Phase 2 coloc_summary at full EUR N (not bootstrapped) -> `unmatched_concordance` per trait. Emit alongside in same TSV as extra column `unmatched_concordance`.

Rewrite `tests/test_matched_n_tier_a.py` (unxfail): synthetic fixture under `tests/fixtures/matched_n/synthetic_bootstraps/` with 2 loci x 5 bootstraps where known retention=0.6 -> assert `mean_retention` is 0.6 +/- sampling tolerance. Also assert CI contains 0.6. Add a test asserting the header comment `D-02e EXPLICITLY NOT REUSED` is present (grep-based regression guard).
