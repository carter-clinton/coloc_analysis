Canonical column schema for ALL replication cohorts after harmonization:
```
CHR    (int)     chromosome 1-22
BP     (int)     GRCh37 position (post-liftover)
SNP    (str)     rsid or chr:pos:ref:alt
EA     (str)     effect allele
OA     (str)     other allele
BETA   (float)   effect size
SE     (float)   standard error
P      (float)   p-value
EAF    (float)   effect allele frequency
N      (int)     sample size
N_CASES (int)    for binary traits (nullable)
N_CTRLS (int)    for binary traits (nullable)
```

Per-cohort raw column → canonical map (from RESEARCH §1-4):
- FinnGen R12: `#chrom→CHR, pos→BP, ref→OA, alt→EA, rsids→SNP, beta→BETA, sebeta→SE, pval→P, af_alt→EAF`
- BBJ hum0197-v3: `CHR→CHR, POS→BP, SNPID→SNP, Allele1→OA, Allele2→EA, Beta→BETA, SE→SE, p.value→P, AF→EAF, N→N`
- MVP REGENIE: `CHROM→CHR, POS→BP, REF→OA, ALT→EA, ID→SNP, A1=ALT, A1_FREQ→EAF, BETA→BETA, SE→SE, LOG10P→P (convert: 10^-LOG10P), N→N`
- GBMI: `CHR→CHR, POS→BP, REF→OA, ALT→EA, rsid→SNP, all_meta_beta→BETA, all_meta_sebeta→SE, all_meta_pval→P, all_meta_AF→EAF, all_meta_sample_N→N`
