2. Create src/snakemake/scripts/run_mvmr.R:
   ```
   #!/usr/bin/env Rscript
   # Phase 3 Plan 04: MVMR for mediation triangles (D-01b).
   # 3 triangles: BMI->Stroke adj HTN, BMI->T2D adj HTN, HTN->T2D adj BMI.
   # Uses MVMR package (Sanderson et al. 2021 Stat Med).
   ```
   CLI args:
   - --instruments-exp1: Path to exposure1 instrument TSV
   - --instruments-exp2: Path to exposure2 instrument TSV
   - --outcome-sumstats: Path to outcome harmonized .bgz
   - --exposure1-name, --exposure2-name, --outcome-name: Trait names
   - --ancestry: Ancestry
   - --mr-config: Path to config/mr_config.yaml
   - --output: Output MVMR results TSV

   Core logic:
   a. Read instruments for both exposures. Take UNION of SNP sets (by snp_id).
   b. For each SNP in the union, look up betas/SE in both exposure instrument tables. If a SNP is an instrument for exposure1 but not exposure2, look up exposure2's beta/SE from its harmonized sumstats at that position.
   c. Look up outcome betas/SE from outcome harmonized sumstats at instrument positions.
   d. Format for MVMR:
      ```r
      mvmr_input <- MVMR::format_mvmr(
        BXGs = cbind(exp1_betas, exp2_betas),  # N_snps x 2
        BYG = outcome_betas,                     # N_snps vector
        seBXGs = cbind(exp1_se, exp2_se),
        seBYG = outcome_se,
        RSID = snp_ids
      )
      ```
   e. Conditional F-statistics (Sanderson 2021):
      ```r
      cond_f <- MVMR::strength_mvmr(r_input = mvmr_input, gencov = 0)
      ```
   f. Q-statistic pleiotropy test:
      ```r
      pleio <- MVMR::pleiotropy_mvmr(r_input = mvmr_input, gencov = 0)
      ```
   g. IVW-MVMR estimates:
      ```r
      mvmr_res <- MVMR::ivw_mvmr(r_input = mvmr_input)
      ```
   h. Write output TSV with: exposure1, exposure2, outcome, ancestry, exposure1_beta, exposure1_se, exposure1_pval, exposure2_beta, exposure2_se, exposure2_pval, cond_f_exposure1, cond_f_exposure2, Q_stat, Q_pval, n_instruments, status.

   ```
   #!/usr/bin/env Rscript
   # Phase 3 Plan 04: Trans-ancestry meta-MR (D-02b).
   # Primary: Fixed-effects meta of ancestry-specific IVW via metafor::rma.uni.
   # Sensitivity: TEMR (Liu et al. AJHG 2025) if available.
   ```

   - --mr-results-dir: Directory containing {exposure}_to_{outcome}.{ancestry}.mr_results.tsv
   - --exposure: Exposure trait
   - --outcome: Outcome trait

   - --output: Output meta-MR TSV

   Core logic:
   a. For each ancestry, read the bidirectional MR results TSV. Extract IVW row (method == "mr_ivw"). Get beta, se, pval.
   b. If only 1 ancestry has IVW results: passthrough (meta_beta = that beta, n_ancestries = 1).

      ```r
      yi <- c(eur_ivw_beta, afr_ivw_beta, ...)
      sei <- c(eur_ivw_se, afr_ivw_se, ...)
      fit <- metafor::rma.uni(yi = yi, sei = sei, method = "FE")
      meta_beta <- as.numeric(fit$beta)
      meta_se <- as.numeric(fit$se)
      meta_pval <- fit$pval
      Q <- fit$QE
      Q_pval <- fit$QEp
      I2 <- fit$I2
      ```

      ```r
      temr_res <- tryCatch({
        requireNamespace("TEMR", quietly = TRUE)
        # TEMR::TEMR() call with exposure/outcome instruments per ancestry
        # ... format per TEMR package docs
      }, error = function(e) {
        message("TEMR not available: ", e$message)
        NULL
      })
      ```
