   ```
   #!/usr/bin/env Rscript
   # Phase 3 Plan 03: Run bidirectional MR for one directed pair.
   # Methods: IVW (RE), Egger, weighted median, MR-PRESSO, + MR-RAPS for non-EUR (D-04a).
   # Steiger: flags instruments, does NOT drop (D-04c).
   ```
   CLI args via optparse:
   - --exposure-instruments: Path to exposure instrument TSV from Plan 03-02
   - --outcome-sumstats: Path to outcome harmonized sumstats .bgz
   - --exposure-name: Exposure trait name
   - --outcome-name: Outcome trait name
   - --ancestry: EUR, AFR, or EAS
   - --mr-config: Path to config/mr_config.yaml
   - --output: Output MR results TSV path
   - --output-harmonized: Output harmonized data TSV path (for downstream MVMR/aggregation)

   Core logic:
   a. Read exposure instruments. Format via TwoSampleMR::format_data(type="exposure") with columns mapped: snp_col="snp_id", beta_col="beta", se_col="se", effect_allele_col="effect_allele", other_allele_col="other_allele", eaf_col="eaf", pval_col="pval", samplesize_col="samplesize".
   b. Read outcome sumstats at instrument positions: extract rows matching instrument chr:pos from the .bgz file. Format via TwoSampleMR::format_data(type="outcome").
   c. Harmonize: TwoSampleMR::harmonise_data(exposure_dat, outcome_dat, action=2). If effect_allele is NA for exposure (bmi.EUR case), use action=3 (drop all palindromic).
   d. Run primary methods:
      ```r
      method_list <- c("mr_ivw", "mr_egger_regression", "mr_weighted_median")
      if (ancestry != "EUR") method_list <- c(method_list, "mr_raps")
      res <- tryCatch(
        TwoSampleMR::mr(dat, method_list = method_list),
        error = function(e) {
          message("TwoSampleMR::mr failed: ", e$message)
          data.frame(method=method_list, b=NA, se=NA, pval=NA, nsnp=0)
        }
      )
      ```
   e. MR-PRESSO (separate call, tryCatch):
      ```r
      n_snps <- nrow(dat[dat$mr_keep == TRUE, ])
      presso_res <- if (n_snps >= 4) {
        tryCatch(
          MRPRESSO::mr_presso(
            BetaOutcome = "beta.outcome", BetaExposure = "beta.exposure",
            SdOutcome = "se.outcome", SdExposure = "se.exposure",
            OUTLIERtest = TRUE, DISTORTIONtest = TRUE,
            data = as.data.frame(dat[dat$mr_keep == TRUE, ]),
            NbDistribution = 1000, SignifThreshold = 0.05
          ),
          error = function(e) { message("PRESSO failed: ", e$message); NULL }
        )
      } else NULL
      ```
      Format PRESSO results into same output schema (method="mr_presso", beta, se, pval, nsnp, n_outliers, global_p, distortion_p).
   f. MR-RAPS (also for EUR as additional check, mandatory for non-EUR):
      For non-EUR ancestries, always include. For EUR, include as supplementary.
      ```r
      raps_res <- tryCatch(
        TwoSampleMR::mr(dat, method_list = "mr_raps"),
        error = function(e) { data.frame(method="mr_raps", b=NA, se=NA, pval=NA, nsnp=0) }
      )
      ```
   g. Heterogeneity + pleiotropy:

2. Create src/snakemake/scripts/run_cause.R:
   ```
   #!/usr/bin/env Rscript
   # Phase 3 Plan 03: CAUSE analysis (Morrison et al. 2020) for one directed pair.
   # CAUSE requires genome-wide summary statistics (NOT just instruments).
   # Uses local PLINK LD clumping (not ieugwasr API — HPC has no internet).
   # CRITICAL: Must use cause v1.2.0 (v1.1.0 has loo_compare bug).
   ```
   CLI args:
   - --exposure-sumstats: Path to exposure harmonized .bgz
   - --outcome-sumstats: Path to outcome harmonized .bgz
   - --exposure-name: Exposure trait
   - --outcome-name: Outcome trait
   - --ancestry: Ancestry (used to select LD reference)
   - --ld-ref-prefix: Path prefix to plink reference (e.g., data/reference/ldsc/1000G_EUR_Phase3_plink/1000G.EUR.QC)
   - --plink2-bin: Path to plink2 binary (from conda env)
   - --mr-config: Path to config/mr_config.yaml
   - --output: Output CAUSE results TSV
   - --temp-dir: Temporary directory for LD clumping intermediate files

   Core logic:
   a. Verify CAUSE version: stopifnot(packageVersion("cause") >= "1.2.0").
   b. Read both genome-wide sumstats via data.table::fread (zcat for .bgz). Select: SNP_ID, CHR, POS, BETA, SE, P, and alleles if available.
   c. Merge exposure + outcome on SNP_ID (or chr:pos if SNP_ID format differs):
      ```r
      X <- cause::gwas_merge(
        exp_df, out_df,
        snp_name_cols = c("SNP_ID", "SNP_ID"),
        beta_hat_cols = c("BETA", "BETA"),
        se_cols = c("SE", "SE"),
        A1_cols = c("effect_allele", "effect_allele"),
        A2_cols = c("other_allele", "other_allele")
      )
      ```
      If alleles missing (bmi.EUR), use only SNP_ID/chr:pos matching and skip allele harmonization (gwas_merge may error — fallback to manual merge on position).
   d. Check variant count: if nrow(X) < cause_config$min_variants (100K), emit warning row and return.
   e. Estimate nuisance parameters:
      ```r
      set.seed(cause_config$seed)  # 42
      varlist <- sample(X$snp, min(1e6, nrow(X)))
      params <- cause::est_cause_params(X, varlist)
      ```
   f. LD pruning using LOCAL plink2 (not ieugwasr API):
      - Write exposure top variants (p1 < cause_config$top_pval_threshold) to temp file
      - Run plink2 --bfile {ld_ref_prefix} --extract temp_file --clump --clump-r2 {ld_prune_r2} --out temp_clumped
      - Read clumped SNP list
      - If plink2 clumping fails (e.g., allele mismatch), fallback to cause built-in LD pruning via random thinning
   g. Fit CAUSE model:
      ```r
      res <- cause::cause(X = X, variants = pruned_vars, param_ests = params)
      ```
   h. Extract results: summary(res) gives z-score for causal vs sharing model, p-value, eta (causal effect), q (shared effect).
   i. Write output TSV with columns: exposure, outcome, ancestry, model_comparison, z_score, p_value, causal_beta (eta), causal_se, sharing_beta (q), sharing_se, n_variants_merged, n_variants_pruned, rho_estimate (sample overlap from params), status.
