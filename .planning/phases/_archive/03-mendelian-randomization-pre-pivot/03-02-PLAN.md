2. Create src/snakemake/scripts/extract_mr_instruments.R:
   ```
   #!/usr/bin/env Rscript
   # Phase 3 Plan 02: Extract MR instruments from SuSiE credible sets.
   # Per D-03a: lead SNP (highest PIP) per credible set.
   # Per D-03b: complex regions included but flagged.
   # Per D-03d: FIQT-corrected betas merged from Phase 9 output.
   ```
   CLI args via optparse:
   - --susie-dir: Directory containing {trait}.{ancestry}.{region}.fit.rds and .json files
   - --trait: Trait name
   - --ancestry: Ancestry name
   - --fiqt-path: Path to discovery_beta_fiqt.tsv (optional; if NULL, use raw betas)
   - --sumstats-path: Path to harmonized sumstats .bgz (for allele/EAF recovery)
   - --bim-prefix: Path prefix to 1000G bim files (e.g., data/reference/ldsc/1000G_EUR_Phase3_plink/1000G.EUR.QC) for allele fallback
   - --mr-config: Path to config/mr_config.yaml (for complex_regions list)
   - --output: Output TSV path
   - --sample-size: Total sample size for F-stat computation

   Core logic:
   a. List all .fit.rds files matching {trait}.{ancestry}.*.fit.rds in susie-dir.
   b. For each .fit.rds:
      - Read the JSON sidecar ({trait}.{ancestry}.{region}.json). If status != "ok", skip.
      - readRDS(fit_rds_path). Call susieR::susie_get_cs(fit). If no CS (length 0), skip.
      - For each CS: find the index with highest pip (fit$pip[idx]). Extract the lead variant.
      - Get variant name from fit$V or names(fit$pip) at that index (annotate_susie stored names).
      - Parse variant name to get chr:pos (format may be "chr:pos:ref:alt" or rsID).
      - Build row: snp_id (from variant name or recovered later), chr, pos, beta (from fit$mu[l, idx] where l is the CS index), se (from sqrt(fit$mu2[l,idx] - fit$mu[l,idx]^2) or from sumstats), pip, cs_id, region_id (from JSON).
   c. BETTER APPROACH for beta/se: Rather than extracting from the SuSiE fit object internal matrices (which are L x p), read the beta/se from the harmonized sumstats at the lead SNP position. The SuSiE fit stores transformed values; the original GWAS betas are the correct MR instruments.
      - Read harmonized sumstats via data.table::fread(cmd = sprintf("zcat %s", sumstats_path)), select CHR, POS, BETA, SE, P, N, SNP_ID and optionally REF, ALT, EAF.
      - Join instruments (chr, pos) to sumstats (CHR, POS) to recover GWAS beta, se, p, snp_id, and alleles.
   d. FIQT merge: If --fiqt-path is provided and file exists:
      - Read FIQT file. Columns: rsid, beta, se, n, beta_FIQT, se_FIQT.
      - Join on snp_id == rsid (or chr:pos fallback).
      - Replace beta with beta_FIQT and se with se_FIQT where available.
   e. Allele recovery fallback (Pitfall 1): If effect_allele or other_allele is NA after sumstats join:
      - Read bim file for appropriate chromosome: {bim_prefix}.{chr}.bim
      - Join on chr + pos to recover A1, A2 as effect_allele, other_allele.
      - If bim also has no match, set alleles to NA and log warning.
   f. Complex region flagging: Read complex_regions from mr_config.yaml. Set complex_region=TRUE if region_id matches any entry (substring match, since region_id format is like "HLA_6p21_3" and config has "HLA_6p21").
   g. Compute F-stat per instrument: f_stat = (beta / se)^2. Cap at diagnostics.f_stat_cap from mr_config.yaml (default 1e6) to prevent overflow.
   h. Write output TSV with columns: snp_id, chr, pos, beta, se, pval, eaf, effect_allele, other_allele, f_stat, pip, cs_id, region_id, complex_region, trait, ancestry, samplesize.

2. Create src/snakemake/scripts/compute_mr_diagnostics.R:
   CLI args:
   - --instruments: Path to {trait}.{ancestry}.instruments.tsv from Task 1
   - --trait: Trait name
   - --ancestry: Ancestry name
   - --output: Output diagnostics TSV path

   Logic:
   a. Read instruments TSV via data.table::fread.
   b. If nrow == 0: emit single row with n_instruments=0, all diagnostics NA. Return.
   c. F-stat already in input (f_stat column). Compute summary stats:
      - mean_f = mean(f_stat)
      - median_f = median(f_stat)
      - min_f = min(f_stat)
      - n_weak_f10 = sum(f_stat < 10)
   d. Per-SNP R^2: r2_snp = f_stat / (f_stat + samplesize - 2). Total R^2 = sum(r2_snp).
   e. Cochran's Q and I^2 (for IVW heterogeneity across instruments):
      - Q = sum(w_j * (beta_j - beta_ivw)^2) where w_j = 1/se_j^2, beta_ivw = sum(w*beta)/sum(w)
      - I^2 = max(0, (Q - (K-1)) / Q) where K = number of instruments
      - Q p-value = pchisq(Q, df = K-1, lower.tail = FALSE)
   f. Output single-row TSV with columns: trait, ancestry, n_instruments, mean_f, median_f, min_f, n_weak_f10, total_r2, i_squared, cochran_q, cochran_q_pval, f_stat_distribution (JSON array of all f_stats for supplementary plotting).
