Create **src/python/run_ldsc_partitioned.py** — LDSC partitioned heritability wrapper.

CLI interface: `python run_ldsc_partitioned.py --step {munge|h2|compute-ld-scores} [step-specific args]`

**Step: munge** (`--step munge`)
```
python run_ldsc_partitioned.py --step munge \
  --ldsc-dir tools/ldsc \
  --sumstats data/processed/sumstats_harmonized/bmi_EUR.tsv \
  --hapmap3 data/reference/ldsc/w_hm3.snplist \
  --sample-size 500000 \
  --out results/pathway/ldsc_partitioned/munged/bmi_EUR
```
Calls munge_sumstats_ldsc.py to pre-format, then calls `python {ldsc_dir}/ldsc.py --sumstats {pre_formatted} --merge-alleles {hapmap3} --out {out} --N {sample_size}`. For binary traits, accept --n-case and --n-ctrl and pass effective N.

Critical per Pitfall 2: After munging, verify the output .sumstats.gz has > 500,000 SNPs (LDSC expects ~1.2M HapMap3 SNPs). If < 500,000, log a WARNING about potential column mismatch. Check that the LDSC log shows intercept estimate (confirms munging succeeded).

**Step: compute-ld-scores** (`--step compute-ld-scores`)
Compute LD scores for custom annotations using `ldsc.py --l2`:
```
python run_ldsc_partitioned.py --step compute-ld-scores \
  --ldsc-dir tools/ldsc \
  --annot-prefix results/pathway/ldsc_partitioned/annotations/custom_pathway \
  --bfile-prefix data/reference/ldsc/1000G_Phase3_plinkfiles/1000G.EUR.QC \
  --out-prefix results/pathway/ldsc_partitioned/ld_scores/custom_pathway
```
Runs per chromosome: `python {ldsc_dir}/ldsc.py --l2 --bfile {bfile}.{chr} --ld-wind-cm 1 --annot {annot}.{chr}.annot.gz --out {out}.{chr} --print-snps {hapmap3}`

**Step: h2** (`--step h2`)
```
python run_ldsc_partitioned.py --step h2 \
  --ldsc-dir tools/ldsc \
  --sumstats results/pathway/ldsc_partitioned/munged/bmi_EUR.sumstats.gz \
  --ref-ld-chr data/reference/ldsc/baselineLD_v2.2/baselineLD.,results/pathway/ldsc_partitioned/ld_scores/custom_pathway. \
  --w-ld-chr data/reference/ldsc/weights_hm3_no_hla/weights. \
  --frqfile-chr data/reference/ldsc/1000G_Phase3_frq/1000G.EUR.QC. \
  --out results/pathway/ldsc_partitioned/bmi_EUR_pathway_h2
```
Runs: `python {ldsc_dir}/ldsc.py --h2 {sumstats} --ref-ld-chr {ref_ld_chr} --w-ld-chr {w_ld_chr} --overlap-annot --frqfile-chr {frqfile_chr} --out {out}`

**CRITICAL per anti-pattern:** Always include `--overlap-annot` flag. Always include baseline v2.2 as first entry in --ref-ld-chr (D-04a). Custom pathway LD scores appended after baseline.

All subprocess calls use list args (NOT shell=True). Validate inputs exist before calling LDSC.

Parse output .results file to extract per-annotation: Prop._SNPs, Prop._h2, Prop._h2_std_error, Enrichment, Enrichment_std_error, Enrichment_p. Write a clean TSV summary.

Create **src/python/run_ldsc_seg.py** — LDSC-SEG tissue-specific heritability wrapper per D-05a.

CLI: `python run_ldsc_seg.py --ldsc-dir DIR --sumstats MUNGED.sumstats.gz --ref-ld-chr BASELINE_PREFIX --w-ld-chr WEIGHTS_PREFIX --ldcts-file LDCTS --out OUTPUT`

Two analysis modes per D-05a:

1. **GTEx gene expression** (`--ldcts-file Multi_tissue_gene_expr.ldcts`):
   Uses pre-built 53-tissue RNA-seq annotations from Finucane 2018. The .ldcts file maps tissue names to LD score file paths.

2. **Roadmap chromatin** (`--ldcts-file Multi_tissue_chromatin.ldcts`):
   Uses Roadmap Epigenomics chromatin state annotations.

Runs: `python {ldsc_dir}/ldsc.py --h2-cts {sumstats} --ref-ld-chr {ref_ld_chr} --ref-ld-chr-cts {ldcts_file} --w-ld-chr {w_ld_chr} --out {out}`

Parse output .cell_type_results.txt to extract per-tissue: Name, Coefficient, Coefficient_std_error, Coefficient_z-score, Coefficient_P_value. Write clean TSV summary.

**Post-processing for D-05b:** Create a function `identify_shared_tissues(seg_results, trait_pairs)` that:
1. For each trait pair (e.g., bmi-t2d, hypertension-stroke), finds tissues significant in BOTH traits (P < 0.05 after Bonferroni across tissues)
2. Reports whether pleiotropic loci preferentially fall in these shared tissues
3. Outputs a summary table: trait1, trait2, shared_tissue, p_trait1, p_trait2

All subprocess calls use list args (NOT shell=True).

Important .ldcts path handling per Pitfall 8: The downloaded .ldcts files may have absolute paths from the Broad download. If `--fix-ldcts-paths` flag is set, rewrite the .ldcts file with paths relative to the annotation directory. Verify the .ldcts file exists and contains valid tab-separated entries before calling LDSC.
