**E. Create src/python/sumstats_utils.py** — Shared utility module for cross-method sumstats operations. Contains:
- `compute_effective_n(n_case, n_ctrl)`: returns `4.0 / (1.0/n_case + 1.0/n_ctrl)`. Used by MAGMA, LDSC, and HESS wrappers — do NOT reimplement in individual scripts.
- `TRAIT_TYPE`: dict mapping trait names to "binary"/"quantitative" (e.g., `{"bmi": "quantitative", "t2d": "binary", "hypertension": "binary", "stroke": "binary", "asthma": "binary"}`).
- `get_effective_n(trait, n, n_case=None, n_ctrl=None)`: convenience function that dispatches to `compute_effective_n` for binary traits or returns `n` for quantitative traits.

**F. Create src/python/munge_sumstats_ldsc.py** — Script to convert project harmonized sumstats to LDSC-compatible format for munge_sumstats.py input. Handles: effective N for binary traits via `from sumstats_utils import get_effective_n` — NOT reimplemented locally. CLI: `python munge_sumstats_ldsc.py --input INPUT --output OUTPUT [--n-case N --n-ctrl N]`.
