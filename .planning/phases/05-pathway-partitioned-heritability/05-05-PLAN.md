Create **src/python/extend_null_genesets.py** — Gene-set-level permutation null generator per D-06c.

CLI: `python extend_null_genesets.py --query-genes GENES.txt --gene-loc GENE_LOC --maf-reference MAF_PREFIX --ld-score-reference LDSCORE_PREFIX --n-permutations 1000 --seed 42 --out-dir OUTPUT_DIR`

**IMPORTANT: `--maf-reference` and `--ld-score-reference` are REQUIRED arguments (no fallback).** These correspond to `pipeline.yaml pathway.maf_reference` (1000G_Phase3_frq) and `pathway.ld_score_reference` (baselineLD_v2.2). D-06c mandates 3-criterion matching — do NOT implement a 2-criterion fallback.

Algorithm per D-06c (1000 permutation null gene sets matched for length, LD, MAF):
1. Read the query gene list (colocalization-derived Tier A+B genes from Phase 2)
2. Read gene location file (NCBI37.3.gene.loc) to get gene coordinates
3. For each query gene, compute ALL THREE matching criteria:
   (a) Gene length (END - START)
   (b) LD complexity: count of independent LD blocks within gene boundaries, computed from baselineLD_v2.2 LD scores — count SNPs with LD score > 2x chromosome mean as proxy for tagging independent signals. This is LD complexity matching per D-06c, NOT gene density.
   (c) Median MAF of SNPs within gene boundaries from 1000G_Phase3_frq files (REQUIRED — no fallback to density-only matching)
4. For each permutation (1 to n_permutations):
   - For each query gene, sample a replacement gene matched within tolerances on ALL 3 criteria:
     - Gene length: +/- 50% (tolerance=0.5)
     - LD block count: +/- 30% (tolerance=0.3)
     - Median MAF: +/- 30% (tolerance=0.3)
     - Exclude: query genes themselves, genes in negative control sets, genes in existing custom pathways
   - Use deterministic seed: seed_base + permutation_index (per T-02-18 pattern)
   - Write the matched null gene set to OUTPUT_DIR/null_geneset_{i:04d}.txt
5. Write a summary: OUTPUT_DIR/null_geneset_summary.tsv with columns: permutation_id, n_genes, mean_gene_length, mean_gene_density

Also export `generate_null_genesets(query_genes, gene_loc_path, n_perm, seed)` as reusable function.
