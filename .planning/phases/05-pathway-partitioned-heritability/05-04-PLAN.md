Create **src/python/run_hess.py** — HESS/rho-HESS local genetic covariance wrapper per D-02a/D-02b/D-02c.

CLI: `python run_hess.py --step {local-rhog|combine|compare} [step-specific args]`

**Step: local-rhog** (`--step local-rhog`)
Run rho-HESS for a single trait pair x ancestry x chromosome.
```
python run_hess.py --step local-rhog \
  --hess-script tools/hess/hess.py \
  --python27 /path/to/hess_env/bin/python \
  --bfile data/reference/hess/ld_panel/EUR/chr22 \
  --partition data/reference/hess/partition/chr22.bed \
  --sumstats1 data/processed/sumstats_harmonized/bmi_EUR_hess.tsv \
  --sumstats2 data/processed/sumstats_harmonized/t2d_EUR_hess.tsv \
  --chrom 22 \
  --out results/pathway/hess/bmi_t2d_EUR_chr22
```
Because HESS is Python 2.7, this wrapper (Python 3) must invoke HESS via `subprocess.run([python27_path, hess_script, ...])` where python27_path points to the hess_py27 conda env's python binary.

HESS sumstats format: requires columns SNP, A1, A2, Z, N. Create a helper function `harmonized_to_hess(input_path, output_path, sample_size)` that reads the project harmonized format and outputs HESS-compatible format. Compute Z from BETA/SE. Use effective N for binary traits.

**Step: combine** (`--step combine`)
Combine per-chromosome results for a trait pair x ancestry.
```
python run_hess.py --step combine \
  --hess-script tools/hess/hess.py \
  --python27 /path/to/hess_env/bin/python \
  --prefix results/pathway/hess/bmi_t2d_EUR \
  --out results/pathway/hess/bmi_t2d_EUR_combined
```
Runs: `python hess.py --prefix {prefix} --out {out}`
Produces: combined local genetic covariance estimates per partition.

**Step: compare** (`--step compare`)
Compare local covariance at pleiotropic loci vs genome-wide average per D-02c.
```
python run_hess.py --step compare \
  --combined-results results/pathway/hess/bmi_t2d_EUR_combined.txt \
  --regions-curated config/regions_curated.csv \
  --out results/pathway/hess/bmi_t2d_EUR_pleio_vs_bg.tsv
```

Algorithm for compare step:
1. Read the combined rho-HESS output (per-partition local covariance estimates with SE)
2. Read config/regions_curated.csv to get pleiotropic loci coordinates (chr, start, end)
3. Map partitions to pleiotropic loci: a partition overlaps if its [start, end] interval intersects a pleiotropic locus [start, end]
4. Split partitions into "pleiotropic" (overlapping any curated locus) and "background" (all others)
5. Compute mean local covariance for pleiotropic partitions vs background partitions
6. Compute z-score: z = (mean_pleio - mean_bg) / sqrt(se_pleio^2/n_pleio + se_bg^2/n_bg)
7. Report: mean_pleio, mean_bg, ratio (mean_pleio/mean_bg), z_score, p_value, n_pleio_partitions, n_bg_partitions

Also export `compare_pleiotropic_vs_background(combined_path, regions_path)` as reusable function.

**Genome build validation (Open Question 1):** Include a function `validate_hess_panel_build(bfile_prefix)` that reads the .bim file, picks 5 SNPs, and checks their positions against a hardcoded GRCh37 reference (e.g., rs1234 should be at chr1:123456). If positions don't match, raise ValueError with clear message about build mismatch.

All subprocess calls use list args (NOT shell=True).

```python
TRAIT_PAIRS = []
for i, t1 in enumerate(TRAITS):
    for t2 in TRAITS[i+1:]:
        shared_anc = set(TRAIT_ANCESTRIES.get(t1, ANCESTRIES)) & set(TRAIT_ANCESTRIES.get(t2, ANCESTRIES))
        for anc in shared_anc:
            TRAIT_PAIRS.append((t1, t2, anc))
```
