Create **src/python/run_magma.py** — MAGMA 3-step wrapper script.

CLI interface: `python run_magma.py --step {annotate|gene|geneset} [step-specific args]`

**Step 1: annotate** (`--step annotate`)
```
python run_magma.py --step annotate \
  --magma-binary tools/magma_v1.10/magma \
  --snp-loc data/reference/magma/g1000_eur.bim \
  --gene-loc data/reference/magma/NCBI37.3.gene.loc \
  --out results/pathway/magma/gene_annotation
```
Runs: `magma --annotate --snp-loc {snp_loc} --gene-loc {gene_loc} --out {out}`
Produces: `{out}.genes.annot`

**Step 2: gene analysis** (`--step gene`)
```
python run_magma.py --step gene \
  --magma-binary tools/magma_v1.10/magma \
  --bfile data/reference/magma/g1000_eur \
  --pval data/processed/sumstats_harmonized/bmi_EUR.tsv \
  --gene-annot results/pathway/magma/gene_annotation.genes.annot \
  --sample-size 500000 \
  --out results/pathway/magma/bmi_EUR
```
Runs: `magma --bfile {bfile} --pval {pval} N={sample_size} --gene-annot {gene_annot} --out {out}`

Critical per Pitfall 4: Accept `--n-case` and `--n-ctrl` for binary traits (T2D, asthma, hypertension, stroke) and compute effective N = 4 / (1/n_case + 1/n_ctrl). For quantitative traits (BMI), use total N directly. Map trait names to binary/quantitative via a TRAIT_TYPE dict: `{"bmi": "quantitative", "t2d": "binary", "hypertension": "binary", "asthma": "binary", "stroke": "binary"}`.

The --pval flag requires MAGMA-compatible format: at minimum columns `SNP` and `P`. Read the harmonized sumstats, extract SNP + P columns, write to a temp file with header `SNP P`, pass that to MAGMA. Do NOT pass the full harmonized file (MAGMA may choke on extra columns).

Produces: `{out}.genes.raw`, `{out}.genes.out`

**Step 3: gene-set analysis** (`--step geneset`)
```
python run_magma.py --step geneset \
  --magma-binary tools/magma_v1.10/magma \
  --gene-results results/pathway/magma/bmi_EUR.genes.raw \
  --set-annot results/pathway/magma/all_pathways.set \
  --out results/pathway/magma/bmi_EUR_geneset
```
Runs: `magma --gene-results {gene_results} --set-annot {set_annot} --out {out}`
Produces: `{out}.gsa.out` (enrichment results with BETA, BETA_STD, SE, P per gene set)

All subprocess calls use list args (NOT shell=True) per T-05-05. Validate that input files exist before calling MAGMA. Log the exact command being run at INFO level.

Create **src/python/build_gprofiler_bg.py** — Build discoverability-matched background gene list per D-03a.

CLI: `python build_gprofiler_bg.py --sumstats-dir DIR --traits TRAIT1,TRAIT2,... --gene-loc GENE_LOC --window-kb 500 --p-threshold 5e-8 --out OUTPUT.txt`

Algorithm per D-03a (Reimand 2019):
1. For each of the 5 traits (bmi, t2d, hypertension, asthma, stroke), read the harmonized sumstats EUR file (use EUR as the largest-N ancestry for discoverability)
2. Filter to genome-wide significant SNPs (P < 5e-8)
3. Extend each SNP position by +/- window_kb (500 kb per D-03a) to create genomic intervals
4. Merge overlapping intervals (use simple interval merge, no need for bedtools dependency)
5. Intersect merged intervals with gene locations (NCBI37.3.gene.loc) to get background gene symbols
6. Union across all 5 traits
7. Write unique gene symbol list to output file (one gene per line)

Also export `build_union_background(sumstats_paths, gene_loc_path, window_kb=500, p_threshold=5e-8)` as a reusable function.

Create **src/python/run_gprofiler.py** — g:Profiler enrichment wrapper per D-03.

CLI: `python run_gprofiler.py --gene-list GENES.txt --background BG.txt --sources GO:BP,KEGG,REAC --exclude-iea --out OUTPUT.tsv`

Two modes:
1. **REST API mode (default):** Use requests to call g:Profiler REST API at `https://biit.cs.ut.ee/gprofiler/api/gost/profile/` directly. POST JSON with query genes, custom background, sources, significance_threshold_method="fdr", user_threshold=0.05, no_iea=True (per D-03b electronic annotation filtering). Parse JSON response into a TSV with columns: source, term_id, term_name, p_value, q_value (FDR), intersection_size, query_size, term_size, effective_domain_size, genes.
2. **R fallback mode (--use-r):** Generate an R script that calls `gprofiler2::gost()` with `evcodes=TRUE, custom_bg=background_genes, domain_scope="custom", correction_method="fdr"`. Execute via Rscript. Parse the output.

Include negative control validation: if `--negative-control-genes NEGCTRL.txt` is provided, also run enrichment on the negative control gene list with the same background. Append results with a `is_negative_control=TRUE` column.

Handle API errors gracefully: retry 3 times with exponential backoff, validate response schema (must have `result` key), report HTTP status code on failure.
