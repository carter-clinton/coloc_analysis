    - Causal selection: for H3 bin [0.55, 0.65], the chosen (c1, c2) satisfy r² in the bin under the fit panel. If no pair qualifies in a window, the job records `no_qualifying_pair` for that (region, scenario) and writes zero reps (counted, never silently substituted)

    - Coloc identity: the harness output for one rep equals run_coloc_pair_r4.R CLI output on the same fits (PP values equal)
    - Output TSV columns: region, scenario, gen_panel, rep, seed, arm (A1, A2, A3), method (A1_abf_matched, coloc_susie, fallback_abf), pp_h0..pp_h4, pp_h4_max, n_cs_a, n_cs_b, causal_a, causal_b, r2_causal
