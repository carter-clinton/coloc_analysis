    **1. Create `src/python/download_onek1k.py`:**
    CLI script that downloads OneK1K sc-eQTL data with fallback logic.

    Arguments:
    - `--cell-type`: one of the 14 cell types (e.g., "Mono_C")
    - `--output-dir`: local output directory (default: data/raw/onek1k/)
    - `--source`: "eqtl_catalogue" (default) or "onek1k_org"

    Processing logic:
    1. **Primary path (eQTL Catalogue):** Check if QTS000038 is available at `ftp://ftp.ebi.ac.uk/pub/databases/spot/eQTL/sumstats/QTS000038/`. If available, download the per-cell-type dataset files (dataset IDs map cell types to QTD* IDs). The eQTL Catalogue Studies page maps study -> datasets. If the specific study/dataset ID cannot be determined at plan time, the script should:
       a. Check for a `data/raw/onek1k/eqtl_catalogue_dataset_map.json` file.
       b. If not present, query the eQTL Catalogue metadata TSV to discover dataset IDs for QTS000038.
       c. Download `{dataset_id}.all.tsv.gz` + `.tbi` per cell type.
    2. **Fallback path (onek1k.org):** If eQTL Catalogue is unavailable, download from `onek1k.s3.ap-southeast-2.amazonaws.com`. File naming: per-cell-type TSV.gz files. These are GRCh37 -- a liftover step is needed. Use liftover_regions.py logic or pyliftover to convert positions.
    3. Verify download: file exists, size > 0 bytes.

    **2. Create `src/python/harmonize_onek1k.py`:**
    Harmonizes OneK1K sc-eQTL data to the common intermediate TSV format.

    CLI arguments:
    - `--input`: path to OneK1K file (eQTL Catalogue format or onek1k.org format)
    - `--cell-type`: cell type name (e.g., "Mono_C")
    - `--region-chr`, `--region-start`, `--region-end`: GRCh38 region window
    - `--gene-id`: Ensembl gene ID
    - `--source-format`: "eqtl_catalogue" (default) or "onek1k_org"
    - `--qtl-source-config`: path to config/qtl_sources.yaml
    - `--output`: output harmonized TSV path

    Processing logic:
    - **If source_format == "eqtl_catalogue":** Reuse `harmonize_eqtl()` directly. The eQTL Catalogue OneK1K files have the same column schema as GTEx eQTL. Set tissue = cell_type, sdY = 1.0, N = an/2 (or 982 as fallback from config).
    - **If source_format == "onek1k_org":** Custom parsing for onek1k.org TSV format. Map columns to common format. Apply liftover from GRCh37 to GRCh38 if needed (using pyliftover). Set N = 982, sdY = 1.0.

    Also provide importable function: `harmonize_onek1k(input_path, cell_type, region, gene_id, source_format, config) -> pd.DataFrame`.

    **3. Extend `src/snakemake/rules/qtl_download.smk`:**
    Append rules for OneK1K download and harmonization:

    ```python
    # --- OneK1K sc-eQTL download ---
    ONEK1K_RAW_DIR = os.path.join(config["paths"]["data_root"], "raw", "onek1k")

    rule download_onek1k_cell_type:
        """Download OneK1K sc-eQTL data for a single cell type."""
        output:
            tsv=os.path.join(ONEK1K_RAW_DIR, "{cell_type}", "{dataset_id}.all.tsv.gz"),
            tbi=os.path.join(ONEK1K_RAW_DIR, "{cell_type}", "{dataset_id}.all.tsv.gz.tbi"),
        conda:
            "envs/qtl_processing.yml"
        resources:
            mem_mb=2000,
        shell:
            r"""
            mkdir -p $(dirname {output.tsv})
            python src/python/download_onek1k.py \
              --cell-type {wildcards.cell_type} \
              --output-dir $(dirname {output.tsv})
            """

    rule harmonize_onek1k_region:
        """Harmonize OneK1K sc-eQTL data for a single (cell_type, gene, region) triple."""
        input:
            tsv=os.path.join(ONEK1K_RAW_DIR, "{cell_type}", "{dataset_id}.all.tsv.gz"),
            qtl_config="config/qtl_sources.yaml",
        output:
            harmonized=os.path.join(QTL_HARMONIZED_DIR, "sceqtl", "{cell_type}", "{gene_id}", "{region}.harmonized.tsv.gz"),
        params:
            region_chr=lambda wc: _qtl_manifest_field(wc, "chr"),
            region_start=lambda wc: _qtl_manifest_field(wc, "start_grch38"),
            region_end=lambda wc: _qtl_manifest_field(wc, "end_grch38"),
        conda:
            "envs/qtl_processing.yml"
        shell:
            r"""
            mkdir -p $(dirname {output.harmonized})
            python src/python/harmonize_onek1k.py \
              --input {input.tsv} \
              --cell-type {wildcards.cell_type} \
              --region-chr {params.region_chr} \
              --region-start {params.region_start} \
              --region-end {params.region_end} \
              --gene-id {wildcards.gene_id} \
              --qtl-source-config {input.qtl_config} \
              --output {output.harmonized}
            """
    ```
