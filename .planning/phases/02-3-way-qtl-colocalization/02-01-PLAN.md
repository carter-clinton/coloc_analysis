    **2. Create `src/python/liftover_regions.py`:**
    A CLI script that reads `config/regions_curated.csv` and outputs `config/regions_curated_grch38.csv`.
    - Uses `pyliftover` with the UCSC `hg19ToHg38.over.chain.gz` chain file (download to `data/external/liftover/` if not present from https://hgdownload.cse.ucsc.edu/goldenpath/hg19/liftOver/hg19ToHg38.over.chain.gz).
    - For each row: lift start and end coordinates. Use `lo.convert_coordinate(f'chr{chrom}', pos)`. Take the first result (highest confidence).
    - Output CSV columns: `region_id,chr,start_grch37,end_grch37,start_grch38,end_grch38,lead_snp,gene,trait_list,source,lift_status`.
    - `lift_status` = "OK" if both start and end lift successfully, "WARN" if only one lifts, "FAIL" if neither.
    - Validate: start_grch38 < end_grch38, and abs(region_size_grch38 - region_size_grch37) < 100000 (sanity check that liftover didn't produce a wildly different region size).
    - CLI: `python src/python/liftover_regions.py --input config/regions_curated.csv --output config/regions_curated_grch38.csv --chain data/external/liftover/hg19ToHg38.over.chain.gz`
