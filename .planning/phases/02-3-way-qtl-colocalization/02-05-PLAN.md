    **1. Create `src/python/assign_tiers.py`:**
    CLI script that assigns Tier A/B/C to each locus based on GWAS-GWAS coloc + QTL coloc results.

    Arguments:
    - `--input`: path to qtl_coloc_aggregated.tsv (aggregated QTL coloc results from all sources)
    - `--gwas-coloc`: path to Phase 1 GWAS-GWAS coloc results (for trait-trait PP.H4)
    - `--pph4-config`: path to config/pph4_thresholds.yaml
    - `--neg-ctrl-results`: (optional) path to curated_neg_ctrl_results.tsv. When provided, appends negative control rows with tier="negative_control" to the output tier table (REQ-7). This ensures the tier table includes a complete record of negative control behavior for downstream reporting.
    - `--output`: output tier assignment TSV
    - `--sweep`: flag to produce sweep table (tier counts at each threshold) instead of single-threshold assignment

    Processing logic:
    1. Load pph4_thresholds.yaml. Get primary_threshold (0.8) and tier_definitions.
    2. Load QTL coloc aggregated results. Each row has: region, ancestry, qtl_source, tissue, gene_id, PP.H4.abf (QTL coloc PP.H4).
    3. Load GWAS-GWAS coloc results. Each row has: region, ancestry, trait_a, trait_b, PP.H4.abf (GWAS coloc PP.H4).
    4. For each locus (region x ancestry):
       a. Get max GWAS-GWAS PP.H4 across all trait pairs at this locus.
       b. Get best QTL PP.H4 across all (qtl_source x tissue x gene) combos at this locus.
       c. Assign tier:
          - **Tier A** if gwas_pph4 >= primary_threshold AND best_qtl_pph4 >= primary_threshold. Record the resolving gene, tissue, and QTL source.
          - **Tier B** if gwas_pph4 >= primary_threshold AND best_qtl_pph4 >= tier_b.min_pph4_qtl (0.5) but < primary_threshold.
          - **Tier C** if gwas_pph4 >= primary_threshold AND best_qtl_pph4 < tier_b.min_pph4_qtl (0.5) or no QTL results.
       d. For Tier A: record all QTL sources that contributed (not just the best one). This is per D-02c: QTL-source-agnostic.
    5. Output tier assignment table: region, ancestry, tier, best_gwas_pph4, best_qtl_pph4, resolving_gene, resolving_tissue, resolving_qtl_source, all_supporting_sources.
    6. **Negative control rows (when --neg-ctrl-results provided):** Read curated_neg_ctrl_results.tsv. For each negative control locus, assign tier="negative_control" (bypassing the normal A/B/C logic). Append these rows to the output table with an additional column `neg_ctrl_set` indicating which curated set (hla_immune, cosmetic, blood_group) the row belongs to. This supports REQ-7 reporting: the tier table should show that negative controls did NOT reach Tier A.

    **Sweep mode (--sweep flag):**
    For each threshold in sweep_values [0.5, 0.7, 0.8, 0.9]:
    - Recompute tier assignment using that threshold as the cutoff.
    - Count Tier A, B, C per ancestry.
    - Output: threshold, ancestry, n_tier_a, n_tier_b, n_tier_c.

    Also provide importable function: `assign_tier(gwas_pph4, qtl_pph4, threshold) -> str` and `sweep_tiers(results_df, thresholds) -> pd.DataFrame`.
