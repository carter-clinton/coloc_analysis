    CLI script that reads an eQTL Catalogue all-pairs TSV (gzipped, tabix-indexed) and outputs a standardized harmonized TSV for a single gene x tissue x region.

    Arguments:
    - `--input`: path to eQTL Catalogue file (e.g., `data/raw/gtex_v8/QTD000021.all.tsv.gz`)
    - `--region-chr`, `--region-start`, `--region-end`: GRCh38 region window
    - `--gene-id`: Ensembl gene ID to filter on (e.g., ENSG00000140718)
    - `--tissue-name`: tissue label (e.g., Adipose_Subcutaneous)
    - `--tissue-n`: sample size for this tissue (integer)
    - `--qtl-source-config`: path to config/qtl_sources.yaml
    - `--output`: output harmonized TSV path

    Processing logic:
    1. Read input file. If tabix-indexed (.tbi exists), use pysam.TabixFile to query the region. Otherwise use pandas with chunksize and filter.
    2. Filter rows where `chromosome == region_chr` and `position >= region_start` and `position <= region_end`.
    3. Filter rows where `gene_id == gene_id_arg` (match on Ensembl ID prefix, ignoring version suffix like `.12`).
    4. Column mapping from qtl_sources.yaml::sources::gtex_eqtl::columns.
    5. Output columns (the common intermediate format): `variant_id, beta, se, maf, position, N, sdY, gene_id, tissue, pvalue, rsid, chromosome`.
    6. Set `N = an / 2` (from eQTL Catalogue `an` field). Set `sdY = 1.0`.
    7. Drop rows where beta or se is NA or where maf < 0.005 or maf > 0.995.
    8. Write to gzipped TSV.

    Also provide a `harmonize_eqtl(input_path, region, gene_id, tissue_name, tissue_n, config) -> pd.DataFrame` function (importable, not just CLI) for testing.

    ```python
    """eQTL Catalogue download and indexing rules for Phase 2 QTL coloc.

    Downloads per-tissue allpairs summary statistics from the eQTL Catalogue
    FTP server. Each file is ~1-5 GB compressed. Files are downloaded locally
    to avoid rate-limiting on remote tabix queries (Pitfall 5 from RESEARCH.md).
    """
    import os
    import json

    QTL_RAW_DIR = os.path.join(config["paths"]["data_root"], "raw", "gtex_v8")
    QTL_HARMONIZED_DIR = os.path.join(config["paths"]["data_root"], "processed", "qtl_harmonized")

    rule download_eqtl_catalogue:
        """Download a single eQTL Catalogue allpairs file + tabix index."""
        output:
            tsv=os.path.join(QTL_RAW_DIR, "{dataset_id}.all.tsv.gz"),
            tbi=os.path.join(QTL_RAW_DIR, "{dataset_id}.all.tsv.gz.tbi"),
        params:
            ftp_base=config.get("qtl_sources", {}).get("gtex_eqtl", {}).get("ftp_base",
                     "ftp://ftp.ebi.ac.uk/pub/databases/spot/eQTL/sumstats/"),
        resources:
            mem_mb=2000,
        shell:
            r"""
            mkdir -p $(dirname {output.tsv})
            wget -q -O {output.tsv} "{params.ftp_base}{wildcards.dataset_id}/{wildcards.dataset_id}.all.tsv.gz"
            wget -q -O {output.tbi} "{params.ftp_base}{wildcards.dataset_id}/{wildcards.dataset_id}.all.tsv.gz.tbi"
            """

    rule build_tissue_n_lookup:
        """Build tissue -> N sample size lookup JSON."""
        output:
            json=os.path.join(QTL_HARMONIZED_DIR, "gtex_tissue_n_lookup.json"),
        conda:
            "envs/qtl_processing.yml"
        shell:
            r"""
            mkdir -p $(dirname {output.json})
            python src/python/build_tissue_n_lookup.py --output {output.json}
            """

    rule harmonize_eqtl_region:
        """Harmonize eQTL Catalogue data for a single (tissue, gene, region) triple."""
        input:
            tsv=os.path.join(QTL_RAW_DIR, "{dataset_id}.all.tsv.gz"),
            tbi=os.path.join(QTL_RAW_DIR, "{dataset_id}.all.tsv.gz.tbi"),
            qtl_config="config/qtl_sources.yaml",
        output:
            harmonized=os.path.join(QTL_HARMONIZED_DIR, "eqtl", "{dataset_id}", "{gene_id}", "{region}.harmonized.tsv.gz"),
        # Params filled by manifest lookup function in qtl_coloc.smk
        params:
            region_chr=lambda wc: _qtl_manifest_field(wc, "chr"),
            region_start=lambda wc: _qtl_manifest_field(wc, "start_grch38"),
            region_end=lambda wc: _qtl_manifest_field(wc, "end_grch38"),
            tissue_name=lambda wc: _qtl_manifest_field(wc, "tissue"),
            tissue_n=lambda wc: _qtl_manifest_field(wc, "tissue_n"),

            "envs/qtl_processing.yml"

            mkdir -p $(dirname {output.harmonized})
            python src/python/harmonize_eqtl.py \
              --input {input.tsv} \
              --region-chr {params.region_chr} \
              --region-start {params.region_start} \
              --region-end {params.region_end} \
              --gene-id {wildcards.gene_id} \
              --tissue-name {params.tissue_name} \
              --tissue-n {params.tissue_n} \
              --qtl-source-config {input.qtl_config} \
              --output {output.harmonized}
    ```

    **1. Create `src/snakemake/scripts/run_qtl_coloc.R`:**
    This is the most critical file in Phase 2. It is the unified GWAS-vs-QTL coloc.susie runner that all QTL sources feed into.

    ```r
    #!/usr/bin/env Rscript
    # ==========================================================================
    # Phase 2 -- unified GWAS-vs-QTL coloc.susie runner.
    #
    # Accepts a pre-fitted GWAS .fit.rds (from Phase 1 run_susie_rss.R) on the
    # GWAS side, and a harmonized QTL sumstats TSV on the QTL side. Fits
    # SuSiE-RSS on the QTL data and calls coloc.susie(gwas_fit, qtl_fit).
    #
    # All QTL sources (eQTL, sQTL, pQTL, sc-eQTL) produce the same harmonized
    # TSV intermediate format, so this script is source-agnostic.
    # ==========================================================================
    ```

    Arguments (via optparse):
    - `--gwas-fit`: path to Phase 1 .fit.rds (SuSiE object with class "susie")
    - `--qtl-sumstats`: path to harmonized QTL TSV (output of harmonize_*.py)
    - `--ld-matrix`: path to LD .rds matrix (from Phase 1 ld_reference pipeline)
    - `--qtl-source`: string identifying source ("gtex_eqtl", "gtex_sqtl", "ukbppp_pqtl", "onek1k_sceqtl")
    - `--tissue`: tissue or cell type name
    - `--gene-id`: Ensembl gene ID
    - `--region`: region_id from regions_curated
    - `--ancestry`: ancestry code (EUR, AFR, etc.)
    - `--sdy`: numeric sdY value for QTL data (1.0 for GTEx/OneK1K; estimated for pQTL)
    - `--sample-size`: integer N for QTL dataset
    - `--policy`: path to config/susie_policy.yaml
    - `--output`: output JSON path

    Processing logic:
    1. `gwas_fit <- readRDS(opt$gwas_fit)` -- check `inherits(gwas_fit, "susie")`.
    2. Read QTL TSV via `data.table::fread(opt$qtl_sumstats)`.
    3. Match SNPs between GWAS fit and QTL data. The GWAS fit has SNP names in `colnames(gwas_fit$alpha)` (or `gwas_fit$pip` names). QTL data has `variant_id` column. Build the intersection.
    4. Subset the LD matrix to matching SNPs: `ld <- readRDS(opt$ld_matrix)`. Subset rows/cols to intersection SNPs. Reorder to match.
    5. Build QTL dataset list:
       ```r
       qtl_data <- list(
         beta     = qtl_df$beta,
         varbeta  = qtl_df$se^2,
         snp      = qtl_df$variant_id,
         position = qtl_df$position,
         type     = "quant",
         N        = as.integer(opt$sample_size),
         sdY      = as.numeric(opt$sdy),
         MAF      = qtl_df$maf,
         LD       = ld_matrix_subset
       )
       ```
    6. `coloc::check_dataset(qtl_data, req = "LD")` -- validate before fitting.
    7. `qtl_fit <- coloc::runsusie(qtl_data, suffix = 2)` -- fit SuSiE on QTL side.
    8. `res <- coloc::coloc.susie(gwas_fit, qtl_fit)` -- run pairwise coloc.
    9. Build output JSON with keys:
       - `summary`: best pairwise row (max PP.H4.abf) -- dict with PP.H0.abf, PP.H1.abf, PP.H2.abf, PP.H3.abf, PP.H4.abf, nsnps, hit1, hit2, idx1, idx2
       - `all_pairs`: all pairwise comparisons (list of dicts)
       - `n_cs_gwas`: number of GWAS credible sets
       - `n_cs_qtl`: number of QTL credible sets
       - `qtl_source`: opt$qtl_source
       - `tissue`: opt$tissue
       - `gene_id`: opt$gene_id
       - `region`: opt$region
       - `ancestry`: opt$ancestry
       - `n_snps_overlap`: number of SNPs in GWAS-QTL intersection
       - `qtl_n`: opt$sample_size
       - `qtl_sdy`: opt$sdy
    10. Handle edge cases:
        - If n_snps_overlap < 50: write JSON with `status: "too_few_snps"`, skip coloc.
        - If runsusie() fails to converge: retry with `max_iter = 200`, then flag as `status: "qtl_susie_failed"`.
        - If no credible sets on QTL side: write `status: "no_qtl_cs"`.
    11. Write JSON via `jsonlite::write_json(output, opt$output, auto_unbox = TRUE, pretty = TRUE)`.

    **2. Create `src/snakemake/rules/qtl_coloc.smk`:**
    Manifest-driven dispatch for QTL colocalization. Modeled on `coloc.smk` but with QTL-specific manifest.

    ```python
    """Manifest-driven QTL colocalization dispatch (Phase 2).

    Extends the Phase 1 coloc.smk pattern to GWAS-vs-QTL pairwise coloc.
    The QTL coloc manifest cross-joins (locus x tissue x gene) per QTL source.
    Each row maps to a single run_qtl_coloc.R invocation.
    """
    import os
    import pandas as pd

    QTL_COLOC_DIR = os.path.join(config["paths"]["results_root"], "qtl_coloc")

    # Region-safe manifest ID constraint (same pattern as coloc.smk T-1-03)
    wildcard_constraints:
        qtl_coloc_id=r"[A-Za-z0-9_.\-]+",

    def _qtl_coloc_manifest_path():
        return os.path.join(QTL_COLOC_DIR, "qtl_coloc_manifest.tsv")

    def _qtl_coloc_manifest_row(qtl_coloc_id):
        manifest_path = _qtl_coloc_manifest_path()

        row = df[df["qtl_coloc_id"] == qtl_coloc_id]
        if len(row) != 1:
            return None
        return row.iloc[0].to_dict()

    def _qtl_manifest_field(wildcards, field):
        row = _qtl_coloc_manifest_row(wildcards.qtl_coloc_id)
        if row is None:
            return "MISSING_MANIFEST"
        return row.get(field, "MISSING_FIELD")
    ```
