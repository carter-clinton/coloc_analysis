<!-- Common intermediate TSV format (output of ALL harmonize_*.py scripts) -->
Columns: variant_id, beta, se, maf, position, N, sdY, gene_id, tissue, pvalue, rsid, chromosome
- variant_id: chr{chrom}_{pos}_{ref}_{alt} (GRCh38)
- N: integer sample size
- sdY: float (1.0 for eQTL/sQTL, estimated for pQTL)
- gene_id: Ensembl gene ID for eQTL/pQTL; splice junction ID for sQTL
- tissue: tissue name for eQTL/sQTL; protein name for pQTL

<!-- UKB-PPP REGENIE column schema (from RESEARCH.md) -->
Columns: CHROM, GENPOS, ID, ALLELE0, ALLELE1, A1FREQ, INFO, N, BETA, SE, LOG10P
- pvalue = 10^(-LOG10P)
- variant_id must be constructed: chr{CHROM}_{GENPOS}_{ALLELE0}_{ALLELE1}
- N = per-row (varies slightly by protein) or ~54219 from header

<!-- sQTL: same eQTL Catalogue schema, molecular_trait_id is splice junction -->
molecular_trait_id format: "chr16:53700000:53750000:clu_12345" (junction coordinates)
gene_id maps to the gene containing the splice junction

    **1. Create `src/python/harmonize_sqtl.py`:**
    This is a thin wrapper around `harmonize_eqtl.py` since sQTL from eQTL Catalogue has the same column schema. The key difference: `molecular_trait_id` is a splice junction ID (e.g., `chr16:53700000:53750000:clu_12345`), not an Ensembl gene ID.

    CLI arguments: identical to harmonize_eqtl.py (--input, --region-chr, --region-start, --region-end, --gene-id, --tissue-name, --tissue-n, --qtl-source-config, --output).

    Additional argument: `--gene-id` for sQTL means "filter molecular_trait_ids that map to this gene". The mapping is: parse the molecular_trait_id to extract chromosome:start:end, then check overlap with the gene's known coordinates. Alternative simpler approach: the eQTL Catalogue sQTL files include a `gene_id` column alongside `molecular_trait_id` -- filter on `gene_id` directly, keep `molecular_trait_id` in a separate column.

    Processing logic:
    1. Import and reuse `harmonize_eqtl` from harmonize_eqtl.py as the core function.
    2. After harmonization, add column `splice_junction_id = molecular_trait_id` (preserving the junction ID).
    3. The `gene_id` column in output is the Ensembl gene ID (not the splice junction).
    4. The `tissue` column is the sQTL tissue name.
    5. sdY = 1.0, N = an / 2 (same as eQTL).

    Also provide importable function: `harmonize_sqtl(input_path, region, gene_id, tissue_name, tissue_n, config) -> pd.DataFrame`.

    **2. Create `src/python/harmonize_pqtl.py`:**
    Harmonizes UKB-PPP REGENIE output to the common intermediate TSV format.

    CLI arguments:
    - `--input`: path to UKB-PPP per-protein file (e.g., `data/raw/ukbppp/IL6/discovery_chr6_IL6.gz`)
    - `--region-chr`, `--region-start`, `--region-end`: GRCh38 region window
    - `--protein-name`: protein identifier (used as "tissue" in common format)
    - `--sample-size`: N (default 54219 from Sun 2023)
    - `--sdy`: sdY value (pass "estimate" to trigger estimation from data)
    - `--qtl-source-config`: path to config/qtl_sources.yaml
    - `--output`: output harmonized TSV path

    Processing logic:
    1. Read REGENIE output (space or tab-delimited, gzipped). Columns per qtl_sources.yaml::sources::ukbppp_pqtl::columns: CHROM, GENPOS, ID, ALLELE0, ALLELE1, A1FREQ, INFO, N, BETA, SE, LOG10P.
    2. Filter to region: `CHROM == region_chr` and `GENPOS >= region_start` and `GENPOS <= region_end`.
    3. Filter to cis-window: only variants within 1 Mb of protein-encoding gene TSS (per D-03b). The TSS lookup is a separate concern -- for now, the region window itself serves as the cis filter (regions are curated to be around the gene of interest).
    4. Column mapping:
       - `variant_id = f"chr{CHROM}_{GENPOS}_{ALLELE0}_{ALLELE1}"`
       - `beta = BETA`
       - `se = SE`
       - `maf = A1FREQ` (ensure 0 < maf < 1; flip if A1FREQ > 0.5: maf = 1 - A1FREQ)
       - `pvalue = 10**(-LOG10P)` (careful with very large LOG10P values; clip at 1e-300)
       - `position = GENPOS`
       - `N = N` column from data (or --sample-size fallback)
       - `gene_id = protein_name` (for pQTL, gene_id is the protein-encoding gene)
       - `tissue = protein_name` (pQTL "tissue" is the protein measured)
       - `chromosome = CHROM`
       - `rsid = ID` (REGENIE ID field)
    5. sdY handling:
       - If `--sdy` is a float: use that value.
       - If `--sdy` is "estimate": call `estimate_sdy(varbeta=se^2, maf=maf, n=N)` from estimate_sdy.py.
    6. Drop rows where beta or se is NA, or maf < 0.005 or maf > 0.995, or INFO < 0.3.
    7. Write to gzipped TSV with common intermediate columns.

    Also provide importable function: `harmonize_pqtl(input_path, region, protein_name, sample_size, sdy, config) -> pd.DataFrame`.

    **3. Create `src/python/estimate_sdy.py`:**
    Utility for estimating sdY from summary statistics when the trait is not inverse-normal transformed.

    Implements the formula from coloc::est_sdY (Wallace, github.com/chr1swallace/coloc):
    ```
    sdY = sqrt(median(2 * maf * (1 - maf) * (N * varbeta + beta^2)))
    ```
    Where: varbeta = se^2, maf is minor allele frequency, N is sample size, beta is effect size.

    Function: `estimate_sdy(beta: np.array, se: np.array, maf: np.array, n: int) -> float`

    This is used for UKB-PPP pQTL where Olink NPX values may not be unit-variance (Open Question 1 from RESEARCH.md). The estimated sdY is passed to run_qtl_coloc.R via --sdy.
