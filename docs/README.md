# docs/

Manuscript-adjacent notes, methods writing, figure captions, and preserved
analysis narratives from the prior submission.

| Subdir / file | Purpose |
|---|---|
| `legacy/` | Summary documents recovered from the prior `/rs1` analysis: `FINAL_COLOC_SUMMARY.md`, `COMPLETE_ANALYSIS_FINDINGS.md`, `HYPERTENSION_COLOC_*.md`, `AFR_COLOC_*.md`, `PATHWAY_ANALYSIS_SUMMARY.txt`. Read-only context for the revision. |
| `methods/` | Methods-section drafts, one file per analytical phase (populated as phases complete) |
| `figure_captions/` | Figure captions + caption drafts tied to each `figures/figNN_*.pdf` |
| `notes/` | Lab notebook-style notes: decisions, meeting notes, reading notes |
| `osf/` | OSF pre-registration documents + deposit manifests |

Not to be confused with `.planning/` (GSD state) or `manuscript/` (the actual
paper draft).
